# Group-2-Course-Enrollment-System
Final Project in Computer Programming 2 (IT143)

System Description:

The Course Enrollment System is a desktop-based application created using Python and Tkinter. It is designed to help users organize and manage student information, course details, and enrollment records through an easy-to-use graphical interface. The system saves all records in a JSON database file, allowing data to be retained and retrieved whenever the application is reopened. It contains three main sections: Students, Courses, and Enrollments, which work together to support the enrollment process.

Features (CRUD):

The system provides complete Create, Read, Update, and Delete (CRUD) functionality for managing student and course records. Users can register new students and courses, view stored information in tabular form, edit existing records, and remove unwanted entries. In addition, the Enrollment module enables users to assign students to courses, display enrollment information, and cancel enrollments when needed. The system also includes validation features that prevent duplicate student IDs, duplicate course codes, repeated enrollments, and enrollment beyond the maximum course capacity.

Instructions on How to Run the System:

To run the program, download the code then open the downloaded file using Pycharm. Once you open it, you can see three files on the side. Go to the login.py file then run it by pressing the run button on the top or right click and press run 'login'. After running login.py, you need to login which can be done by putting "admin" as the username and "admin1234" as the password. You can press the checkbox to make sure you typed the password correctly. When you finish the login, you will be met by the main interface of the Course Enrollment System wherein you can add, read, update and delete information in the Students, Courses, and Enrollments modules. All modifications made within the system are automatically stored in the database file for future use.
